## 2026-09-12 · 시각 시뮬레이션 개선 계획

1. 선으로 된 나선을 눈·눈벽·끊어진 비구름 띠를 가진 절차적 구름으로 바꿉니다. 별도의 30일 날씨 시계에서 결정론적 생성·발달·이동·전향·쇠퇴를 계산합니다.
2. 온난화에 따라 자체 생성 후보가 늘어나는 확대 실험과 경로 변동 조작을 명확히 표시합니다. 실제 전 세계 태풍 빈도나 예측 경로에 대한 주장과 구분합니다.
3. 작은 빙하 기호를 확대 얼음 영역과 기준 윤곽으로 바꾸고 큰 빙하 후퇴 비교를 추가합니다. 해안만 강조하는 해수면 표시와 읽기 쉬운 가상 해안 단면·눈금을 제공합니다.
4. 순수 모델/렌더 경계, 공유 설정 호환, 정지·복구, 출처·번역 일치를 유지합니다. 모델 불변 조건·데스크톱/모바일 조작·실제 스크린샷을 검증한 뒤 마칩니다.

상태: 로컬 구현·검증 완료. push나 공개 배포는 수행하지 않았습니다.

### 개선 결과

- 선 나선을 절차적 눈·눈벽·구름 띠로 바꿨습니다. 결정적인 바다 생성·발달·조향·전향·과거 경로·육지/차가운 바다에서의 약화를 별도의 30일 날씨 시계에서 계산합니다.
- 명확히 표시한 극한 모드에서는 온난화에 따라 자체 후보와 경로 굴곡을 늘리며 비교 모드는 후보 4개를 고정합니다. 수·모드·조향·날씨 시간을 공유하고 내보낼 수 있습니다.
- 빙하 영역을 키우고 노란 2015년 윤곽과 계곡 후퇴 비교를 제공합니다. 격자 구체를 해안만 강조하는 표현으로 바꾸고 큰 단면에 기준 수면·상승 범위·중간값을 표시합니다.
- 동일한 날씨 모델 문서를 추가하고 모델·아키텍처·출처·사용법·검증 문서를 양언어로 갱신했습니다.

- 모델 테스트는 결정적 동작·불변 조건을 확인하며 예보 정확도를 검증하지 않습니다. 태풍 후보·경로 계수·구름 크기·빙하 후퇴·해안 확대는 자체 설정입니다. 태풍 상호작용·지역 침수·실제 감염병 발생률은 추가하지 않았습니다. 실제 모바일 GPU·Firefox·Safari는 검증하지 않았습니다.

### 검증 중 수정

- 첫 프레임 테스트가 처음에는 시간 초과했습니다. 복잡한 국가 클리핑 경계 안에서 장식 점을 개별적으로 수천 번 그리며 캔버스 실체화가 멈췄습니다. 반복 패턴 한 번 채우기로 바꾼 뒤 지구본 표시와 유휴 렌더링 정지가 정상 동작했습니다.
- 다음 실행은 20개 통과·4개 실패였습니다(두 동작을 두 화면 크기에서 검사). 자체 수온장의 위도에 따른 감소가 기본 열대 태풍 실험에 비해 너무 커 지수를 3으로 조정하고 기본 환경 수온 불변 검사를 추가했습니다. 같은 페이지의 공유 해시 이동 시 대화상자가 남는 문제는 주소 복원 시 창을 닫고 실험실로 돌아가도록 수정했습니다.
- 원문 확인 후 빙하 불확실성 설명을 1 표준편차가 아닌 논문의 **95% 신뢰구간**으로 바로잡았습니다.
- 양언어 출처 검사에서 인라인 URL 옆 백틱/문장 부호를 포함하던 문제를 수정했습니다. 문서 16개가 모두 통과하며 의미·수식·기준 설명도 양언어로 검토했습니다.
- 엘니뇨·라니냐를 명시적 발산 색상 편차 척도로 강화하고 실제 픽셀 변화와 범례를 검증했습니다. 좁은 화면의 한국어 제목 줄바꿈도 개선했습니다.
