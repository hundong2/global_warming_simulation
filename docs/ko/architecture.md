# 아키텍처

## 제품과 경계

Climate Lab은 **지구 실험실**, **기후와 우리**, **함께하는 실천**의 세 화면을 제공하는 한국어 중심 교육용 지구본입니다. 출처 창에서 각 결과의 의미를 설명합니다. 로컬 Natural Earth 지리를 사용하는 정적 Vite + TypeScript + Three.js 사이트입니다.

```text
입력 / URL 해시 → 검증된 Settings → 순수 evaluate()
                                    ├─ 수치 지표 / 비교
                                    ├─ 개념 해양 / 태풍 / 빙하 그림
                                    └─ 내보낸 실험 스냅샷
실천 체크리스트 → 선택적 localStorage (기후 계산과 독립)
```

- `src/simulation/climate.ts`: 설정 타입, 정규화, 참고 표, 보간, 시나리오 계산, URL 직렬화. 렌더링 의존성이 없습니다.
- `src/render/globe.ts`: 로컬 지리 로딩, 지도 텍스처 생성, 지구본, 격자, 빙하·태풍 기호, 카메라, 크기 변경, 그래픽 연결 복구, 자원 해제.
- `src/ui/content.ts`: 한국어 설명, 출처 링크, 실천 카드, 자체 SVG 아이콘.
- `src/main.ts`: 설정 소유, 화면·대화상자 연결, 연도 재생, DOM 결과 갱신, 설정 내보내기.
- `src/style.css`, `src/ui/tokens.css`: 반응형 디자인, 접근 가능한 포커스, 기본 입력 요소, 동작 줄이기 지원.
- `tests/unit/`: 독립 수치 종점과 불변 조건. `tests/e2e/`: 저장소 하위 경로에서 실제 브라우저 조작.
- `scripts/`: 정적 미리보기와 문서·빌드·자료 무결성 검사.

## 렌더링과 생명주기

지구본 반지름은 표시 단위 1입니다. 위도·경도는 `(cos(lat) cos(lon), sin(lat), −cos(lat) sin(lon))`으로 변환합니다. Three.js 텍스처 UV도 같은 규칙을 따릅니다. 초기 카메라는 아시아·서태평양을 향합니다. 드래그, 확대 버튼, 휠·핀치, 캔버스 포커스 후 방향키로 카메라를 조작합니다. 모델은 메시 위치를 읽지 않습니다.

1024×512 절차적 해양 텍스처는 4픽셀 표본과 로컬 국가 폴리곤을 사용합니다. 색은 개념 표층 수온이며 위성 영상이 아닙니다. 위도 기반 육지 색은 가독성을 위한 것으로 식생·고도 자료가 아닙니다. 빙하 기호의 선형 크기는 남은 질량 비율의 세제곱근이며 지역별 예측 면적이 아닙니다. 극지 빙상은 고정합니다. 밝은 해안과 해안 단면은 변화를 과장하며 침수를 계산하지 않습니다.

해양 레이어에서 엘니뇨·라니냐를 선택하면 명확히 표시한 −2~+2°C 편차 척도로 전환합니다. 차가운 편차는 파랑, 중립은 어두운 바다, 따뜻한 편차는 주황입니다. 중립 현상을 선택하면 가상 수온 절대 척도로 돌아갑니다. 태풍 레이어는 계속 가상 수온 절대값을 표시합니다.

픽셀 비율은 1.5로 제한합니다. 유휴 상태에서는 필요한 때만 그립니다. 명시적 자동 회전이나 태풍 재생 중에 애니메이션 프레임을 예약합니다. 시간 실험은 800/400/160 ms마다 1년씩 진행합니다. 2100년에 멈춥니다. 숨긴 화면과 대화상자는 렌더링을 중단하며, 브라우저 탭을 숨기면 시간을 정지합니다. 복귀 첫 프레임은 경과 시간을 0으로 처리해 도약을 방지합니다.

ResizeObserver가 카메라 비율과 화면 크기를 갱신합니다. WebGL 연결이 끊어지면 복구 안내를 표시하고 모델·설명은 유지합니다. 지리 자료 로딩 실패 시 재시도를 제공합니다. 재생성 전 도형·재질·텍스처·이벤트·관찰자·렌더러를 해제합니다. 가짜 대체 WebGL 이미지를 표시하지 않습니다.

## 상태와 공유

공유 값은 허용 목록으로 검증·정규화합니다. 해시에는 시나리오·목표 온도·연도·엘니뇨/라니냐·레이어·시어·습도·위도·대비 수준이 들어갑니다. 로컬 주소는 해당 로컬 서버에 접근할 수 있는 곳에서만 작동하며 공유 창에 안내합니다. JSON에는 스키마 버전·설정·계산 결과·가정·출처 링크를 포함합니다. 개인정보를 수집하지 않습니다.

실천 6개는 localStorage의 `climate-lab-actions-v1`에 저장하며, 저장 불가 시 메모리에서만 유지합니다. 실천 체크는 지구 온도를 바꾸거나 탄소 감축량을 수치로 환산하지 않습니다. 링크는 같은 실험을 재현하며 실시간 다중 사용자 세션이 아닙니다.

## 제공 방식

`base: './'`가 저장소 하위 경로를 지원합니다. 지리는 `import.meta.env.BASE_URL`로 읽습니다. 라우터나 백엔드는 없습니다. `dist/` 전체를 배포합니다. 영어 문서는 기본 경로에 있으며 동등한 한국어 문서와 서로 연결됩니다. [배포 문서](deployment.md)를 참고하세요.
