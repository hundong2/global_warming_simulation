# 날씨 실험과 시각적 축척

[English](../weather-model.md) | **한국어** · [기후 모델](climate-model.md)

## 해석

결정적으로 재현하는 자체 제작 30일 열대저기압 애니메이션 실험입니다. NOAA는 눈·눈벽·나선형 비구름, 환경 조건, 조향·전향의 정성적 개념을 뒷받침하지만 아래 계수를 검증하지는 **않습니다**. [출처](sources.md)를 참고하세요. 후보는 가상 요란이며 관측 태풍·연간 빈도·예보 확률·실제 동시 발생 수가 아닙니다. 온난화로 전 세계 태풍 빈도가 반드시 증가하지 않습니다. 따뜻한 바다는 더 강한 태풍과 많은 강수를 뒷받침할 수 있지만 이 실험은 둘을 물리 단위로 정량화하지 않습니다.

기본 **극한** 모드는 복잡하고 이례적인 상황을 탐색하도록 선택 연도의 온난화에 따라 후보 수와 경로 굴곡을 의도적으로 늘립니다. **비교** 모드는 후보를 4개로 고정하고 조향장에서 온도 영향을 제거합니다. 어느 모드도 기후 전망이 아닙니다. 조향 변화로 굴곡·정체·고리 경로를 만들 수 있으나 온난화가 고리를 늘린다는 설정은 연구 결과가 아닌 실험 가정입니다. 후지와라 효과를 포함한 태풍 상호작용은 생략합니다.

## 순수하고 재현 가능한 상태

`src/simulation/weather.ts`는 검증된 기후 설정과 순수 육지 판정을 받아 0.25일 간격 경로를 반환하고 `weatherDay`(0–30)에서 선형 표본화합니다. 렌더러는 표본을 표시하며 메시 위치를 모델로 되돌리지 않습니다. 기본 날씨 시간은 9일, 모드는 `stress`, `trackVariability`는 65/100입니다. 해시와 JSON이 세 값을 모두 보존합니다. 날씨 시간은 선택한 기후 연도와 별개이며 실제 1초당 대략 가상 1일로 재생하고 30일에 정지합니다.

`T`는 선택 연도의 온난화, `V`는 시어, `H`는 습도, `φ`는 위도, `λ`는 경도(도), `a`는 태풍 나이(일)입니다. `clip`은 0–1로 제한합니다. `t=clip((x−b)/(c−b))`일 때 `S(b,c,x) = t²(3−2t)`입니다. 결정적 시드는 `u(i,n)=fract(sin(i×127.1+n×311.7)×43758.5453)`이며 `fract`는 바닥 정수값을 뺍니다.

```text
Nreference = 4
Nstress = min(12, 4 + floor(max(0,T−1.2)×2.5))
i = 0 ... N−1
birth = (i×3.7) mod 14
φ0 = clamp(latitudeSetting−6 + 12u(i+1,1), 5, 28)
λ0 = 136 + (i×19.3 mod 50) + 8(u(i+1,2)−0.5)
```

기후 생성 환경 점수가 0이면 경로를 만들지 않습니다. 육지에서 시작하면 최대 18번 동쪽으로 2°씩 옮기며 계속 육지이거나 SST가 26.5°C 미만이면 후보를 제외합니다. 화면의 후보 수에는 제외되거나 아직 활성화되지 않은 후보도 포함됩니다. 활성 수는 나이가 0일 초과·16일 미만이고 발달 지수가 0.018 이상인 경우입니다. 따라서 더 따뜻한 극한 시나리오라도 모든 순간에 활성 태풍이 많아지는 것은 아닙니다. 로컬 Natural Earth 폴리곤과 구멍으로 육지를 판정하고 경도를 연결합니다. 작은 섬과 해안 세부 정보는 없습니다.

## 발달과 이동

0.25일 간격마다 현지 SST는 [가상 해양](climate-model.md)에서 가져옵니다. 발달 지수 `I`는 0에서 시작합니다. 풍속·기압·태풍 등급·발생 확률이 아닙니다.

```text
potential = clip((0.42 + 0.15(SST−26.5)) × (1−V/35) × H/85)
surface = 0 when SST < 26.5; otherwise 0.12 on land and 1 over water
equilibrium = S(0,3.5,a) × (1−S(9,16,a)) × potential × surface
Inew = clip(I + (equilibrium−I) × response)
response = 0.35 on land or cold water, otherwise 0.18
B = trackVariability/100 × (stress ? 1+0.22(T−1.2) : 1)
phase = 2πu(i+1,3)
turn = S(19+4u(i+1,4), 32, φ)
envelope = exp(−((a−7)/4)²)
east = −2.1 + 6turn + 3.6B sin(0.95a+phase) × envelope
north = 0.95 + 0.5u(i+1,5) + 2.5B cos(0.95a+phase) × envelope
λnew = λ + east×0.25/max(0.6,cos(φπ/180))
φnew = clamp(φ + north×0.25, 3, 55)
```

East/north는 도식적 도/일이며 계산된 대기 속도가 아닙니다. 경로는 나이 0–16일을 포함합니다. 초기 서진장에서 고위도로 가면 동진하며 진동 섭동으로 불규칙한 조향을 설명합니다. 단계 이름도 예시입니다. 2일 미만은 형성, 5일 미만은 발달, 이후는 성숙, 육지이거나 10일 초과이면 쇠퇴입니다. 공식 강도 분류가 아닙니다. 차가운 바다에서 점차 약해지며 온대저기압 전환·바다 냉각 되먹임·대기 역학·지형별 마찰·계절 주기는 풀지 않습니다.

## 표시 확대

- 구름은 결정적 잡음, 눈, 눈벽, 넓은 구름막, 나선형 띠로 로컬 생성합니다. 발달 지수가 0.42를 넘고 나이가 3일을 넘으면 눈을 표시합니다. 지름은 표시 단위 `0.15+0.22I`, 시어의 한 축 압축은 `1−V/110`, 불투명도는 `0.23+1.3I`를 1로 제한하며 회전은 `1.15a+2.4i` 라디안입니다. 반지름 1인 지구본에서 크기와 속도를 확대해 표현합니다. 금빛 선은 표본화한 과거 경로만 표시하며 예보 원뿔은 없습니다. 지구의 깊이 판정이 뒷면 구름을 가립니다.
- 빙하 기호는 노란 2015년 윤곽을 고정하고 현재 얼음을 남은 질량 비율의 세제곱근으로 축소하며 표시 단위 `0.065×(1−scale)`만큼 산 위로 옮깁니다. 가상 계곡 비교의 빙하 끝은 SVG 단위 `432−3.1×loss`입니다. 과장한 거리이며 지역 면적이나 길이 전망이 아닙니다. 극지 빙상은 고정합니다.
- 해안 강조는 육지 래스터 합집합과 경계 거리를 사용해 국가 내부 경계가 밝아지지 않게 합니다. 표시 띠는 1024×512 지도에서 `1.3+5×seaUpper` 픽셀입니다. 가상 단면은 수직 SVG 단위 `178−98×seaLevel`, 고정 기준 수면, 하한·상한 띠, 중간값 파형 선을 씁니다. 고도 모형을 사용하거나 침수 면적을 추정하지 않습니다.

## 검증 경계

테스트는 재현성, 유한한 범위, 바다 생성, 조건부 육지 약화, 생성 차단, 시간 보간, 생애 종료, 고정·극한 후보 수, 비교 모드의 온도와 조향 독립성, 육지 구멍·기준 위치를 확인합니다. 브라우저 검사는 실제 화면 이동, 정지·종료, 공유 재현, 확대 비교, 반응형 배치를 확인합니다. 구현 동작을 검증하며 예측력을 검증하지 않습니다.
